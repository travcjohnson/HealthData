Import Whoop

Whoop app → Profile → Data export → physiological_cycles.csv. Recovery, sleep, and strain land on the Recovery tab.

Import Strava

strava.com → Settings → My Account → Download your archive → activities.csv. Activities land on the Training tab.

Import Apple Health

iPhone → Health app → profile picture → Export All Health Data, unzip, then drop export.xml here. Handles multi-hundred-MB files by streaming. Pulls daily HRV, resting HR, sleep, steps, VO₂max, and workouts.
